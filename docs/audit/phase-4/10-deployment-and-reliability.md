## Penilaian

Slaude jauh lebih matang secara operasional untuk deployment HA (ditopang Redis + Postgres + k8s). Biayanya kompleksitas operasional tinggi — bertentangan dengan prinsip Level 1 Anvio ("tanpa Docker, tanpa DB").

## Yang relevan untuk Anvio

| Praktik                                                                     | Relevansi                     | Keputusan                                      |
| --------------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------- |
| `/readyz` yang menguji dependensi                                           | Tinggi, murah                 | ADOPT                                          |
| Boot guard: tolak topologi tak aman (mis. multi-replika + storage embedded) | Tinggi untuk Level 3          | ADOPT                                          |
| Node drain pada SIGTERM                                                     | Sedang                        | ADOPT (worker)                                 |
| `unhandledRejection` guard + circuit breaker (N dalam T → exit)             | Tinggi; T-005 sudah log-only  | ADAPT (tambah breaker)                         |
| Antrean Redis + node worker                                                 | Level 3+ saja                 | DEFER (Level 1 pakai antrean in-process T-004) |
| k8s manifests + HPA                                                         | Level 3+                      | DEFER                                          |
| Fake platform wire-level untuk e2e                                          | Tinggi untuk kualitas channel | ADAPT (mulai Slack/Telegram)                   |
| Vault/`env://` referensi kredensial                                         | Sedang                        | DEFER (credential pool sudah ada)              |
