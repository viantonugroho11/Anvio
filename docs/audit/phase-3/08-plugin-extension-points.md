# 08 — Plugin Extension Points

## Titik ekstensi yang paling siap

1. **MCP** — sudah out-of-process dan hot; setelah G-33 dan env allow-list diperbaiki, ini jalur aman paling cepat untuk "tool plugin" pihak ketiga.
2. **Model OpenAI-compatible** — cukup data (base URL + key env).
3. **Skill** — sudah ada installer; kurang versi, pin, dan enforcement izin.

## Titik ekstensi yang butuh perubahan struktural kecil

- **Channel**: `ChannelType` union tertutup + route webhook yang di-hardcode di `gateway-http.ts`.
- **Runtime vendor**: `runtime-factory.ts` statis; `agentRuntimeBindingSchema.provider` adalah enum tertutup.
- **A2A extension**: belum ada registry/negotiator.
