# ADR 0005: NATS JetStream

## Decision
NATS JetStream for event bus.

## Rationale
Lightweight, K8s-native, durable messaging.

## Reconciliation note (2026-10-25)

Status was not recorded; treated as **Accepted**. A NATS JetStream event bus exists (`packages/events/src/event-bus.ts`) and is optional (`events.provider`). The default is the in-process bus per [ADR-0007](0007-local-first-architecture.md). NATS mode was not verified in the 2026-10-24 post-refactoring audit. Original decision text above is unchanged.
